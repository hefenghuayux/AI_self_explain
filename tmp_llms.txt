# 千问AI平台文档

> 千问AI平台提供通义千问大语言模型及多模态 AI 的 API 访问服务，涵盖文本生成、视觉理解、图像生成、视频生成、语音识别、语音合成、语音对话、向量化及重排序等能力，支持 OpenAI 兼容和 DashScope 两种接入方式。

## Token Plan

- [Token Plan 概述](https://platform.qianwenai.com/docs/token-plan/overview.md): Token Plan 是千问AI平台推出的 AI 大模型订阅服务，以 Credits 统一计量，支持多种 AI 编程和智能体工具。提供个人版和团队版两个版本，满足从个人开发者到企业团队的不同需求。
- [Token Plan 个人版](https://platform.qianwenai.com/docs/token-plan/personal/token-plan-personal-overview.md): Token Plan 个人版是面向个人开发者的 AI 大模型订阅服务，以 Credits 统一计量，支持文本、多模态模型及模型内置工具，Standard 与 Pro 套餐附赠 Harness 权益，适配主流 AI 编程和智能体工具。
- [快速开始](https://platform.qianwenai.com/docs/token-plan/personal/token-plan-personal-quickstart.md): 三步完成 Token Plan 个人版订阅和接入
- [Harness 权益](https://platform.qianwenai.com/docs/token-plan/personal/token-plan-harness-benefits.md): Token Plan 个人版 Standard 与 Pro 套餐附赠 Harness 权益，覆盖自研工具的每月免费额度与后付费折扣，使用千问AI平台 API Key 调用，不占用套餐 Credits。
- [接入 Harness 工具](https://platform.qianwenai.com/docs/token-plan/best-practices/built-in-tools.md): 接入 Token Plan 个人版 Harness 权益提供的自研工具，并示例联网搜索增强版 MCP 的接入流程。
- [常见问题](https://platform.qianwenai.com/docs/token-plan/personal/token-plan-personal-faq.md): Token Plan 个人版的额度、购买、订阅和接入常见问题。
- [Token Plan 团队版](https://platform.qianwenai.com/docs/token-plan/team/token-plan-team-overview.md): AI 大模型订阅服务
- [快速开始](https://platform.qianwenai.com/docs/token-plan/team/token-plan-team-quickstart.md): 三步完成 Token Plan 团队版订阅和接入
- [团队管理](https://platform.qianwenai.com/docs/token-plan/team/team-management.md): 在 Token Plan 管理平台中添加和管理团队成员、分配和回收席位、配置 SSO 登录、监控 Credits 用量。
- [常见问题](https://platform.qianwenai.com/docs/token-plan/team/token-plan-team-faq.md): Token Plan 团队版常见问题汇总，涵盖购买、使用、计量和性能相关的问题解答。

## 进阶接入

- [接入决策模型](https://platform.qianwenai.com/docs/token-plan/best-practices/decision-model.md): 通过 AI 工具的扩展机制接入 decision-model-preview 决策模型：以评论自动审核为例，一次请求并行判定多条内容，返回 choice、probabilities、confidence，按置信度自动放行、隐藏或转人工。
- [接入多模态生成模型](https://platform.qianwenai.com/docs/token-plan/best-practices/multimodal-generation.md): Token Plan 中的图像生成、视频生成、语音合成模型需通过工具的扩展机制（Skill、Slash Command 或 Agent）接入

## Managed Agent

- [概述](https://platform.qianwenai.com/docs/agent-infra/managed-agents/introduction.md): Managed Agents 是千问AI平台提供的智能体托管运行时，适用于多步工具调用、代码执行、文件处理等长时运行任务。平台托管会话状态、沙箱环境和工具执行，智能体在独立沙箱中自主执行命令、读写文件、安装依赖并处理数据，事件历史在服务端持久化。
- [快速开始](https://platform.qianwenai.com/docs/agent-infra/managed-agents/overview/quickstart.md): 通过控制台，按 4 步完成智能体创建、环境配置、会话发起与调用。
- [定义 Agent](https://platform.qianwenai.com/docs/agent-infra/managed-agents/build-agent/define-agent.md): 智能体定义模型、系统提示词、工具与扩展能力，每次保存自动产生新版本。
- [Agent 工具配置](https://platform.qianwenai.com/docs/agent-infra/managed-agents/build-agent/tools.md): Managed Agents 提供 9 个内置工具，覆盖命令执行、文件操作、网络访问与产出物标记，全部在会话绑定的运行环境中执行。
- [Agent MCP](https://platform.qianwenai.com/docs/agent-infra/managed-agents/build-agent/mcp.md): MCP（Model Context Protocol）是大模型与外部工具之间的标准协议。在控制台 MCP 管理页面按服务卡片浏览与管理。
- [Agent Skills](https://platform.qianwenai.com/docs/agent-infra/managed-agents/build-agent/skills.md): 技能是打包后的能力集合，封装常见任务的端到端流程。在控制台 Skill 管理页面管理，可被多个智能体复用。
- [多智能体协作](https://platform.qianwenai.com/docs/agent-infra/managed-agents/build-agent/multiagent.md): 通过 coordinator 编队，让一个协调者智能体编排多个成员智能体协同完成任务。
- [云端托管环境](https://platform.qianwenai.com/docs/agent-infra/managed-agents/environment/cloud-hosting.md): 运行环境定义工具调用的执行沙箱。在控制台环境页面创建和管理，可被多个会话复用。
- [发起会话](https://platform.qianwenai.com/docs/agent-infra/managed-agents/sessions/create-session.md): 会话承载智能体的一次运行实例，全部消息、工具调用与状态变更以事件形式实时记录。
- [管理会话](https://platform.qianwenai.com/docs/agent-infra/managed-agents/sessions/manage-sessions.md): 会话创建后，可通过状态机、工具调用审批和中断机制控制执行流程，并在任务完成后归档或删除。
- [会话事件流（SSE）](https://platform.qianwenai.com/docs/agent-infra/managed-agents/sessions/event-stream.md): 会话内的全部交互以事件形式记录。通过 API 订阅时以 SSE（Server-Sent Events）事件流推送。
- [密钥库认证](https://platform.qianwenai.com/docs/agent-infra/managed-agents/sessions/credentials.md): 密钥库是一个保险箱（Vault），集中管理外部服务的鉴权信息。保险箱内存放具体的密钥（API Key、Token 等），在创建会话时绑定，供 MCP 服务和技能在运行时引用。
- [Agent 上下文管理](https://platform.qianwenai.com/docs/agent-infra/managed-agents/context/introduction.md): 通过挂载资源扩展智能体在会话中可访问的数据。资源独立管理，可被多个会话复用。
- [文件上传与挂载](https://platform.qianwenai.com/docs/agent-infra/managed-agents/context/file-upload.md): 文件是独立管理的资源，可被多个会话挂载，生命周期与会话解耦。在控制台文件菜单上传与管理。
- [Webhook 事件订阅](https://platform.qianwenai.com/docs/agent-infra/managed-agents/webhooks/introduction.md): Webhook 将会话、智能体、部署等资源的状态变更事件实时推送到指定回调地址，替代轮询获取最新状态。
- [计费说明](https://platform.qianwenai.com/docs/agent-infra/managed-agents/pricing/billing.md): Managed Agents 的计费项、免费额度与计费示例。
- [入门：搭一个数据分析 Agent](https://platform.qianwenai.com/docs/agent-infra/managed-agents/best-practices/data-analysis.md): 用 curl 走通 Managed Agents REST API 全链路：创建 Agent 与 Environment、上传并挂载数据集、驱动 Session 完成数据体检、清洗与出结论，取回产物并归档资源。
- [进阶：自定义 MCP 与 Skills](https://platform.qianwenai.com/docs/agent-infra/managed-agents/best-practices/custom-mcp-skills.md): 把自有能力挂上 Agent：已运行的 MCP Server 注册进千问AI平台（自定义 MCP，含按会话动态传入鉴权 Header），团队作业流程打包上传（Skills），含运行时机制与版本管理。
- [进阶：构建对话客户端](https://platform.qianwenai.com/docs/agent-infra/managed-agents/best-practices/client-streaming.md): 把 Managed Agents 接入网页或移动端产品：SSE 增量拼接、思考与回合状态处理、断线恢复不重复提交，以及会话内动态挂载与撤下附件。
- [进阶：多模态输入与图片问答](https://platform.qianwenai.com/docs/agent-infra/managed-agents/best-practices/multimodal-image.md): 图片经上传与审核后以 file_id 进入会话：发送图文混合消息、用可控图片验证识别结果，以及当前的模型与输入格式限制。
- [进阶：生产化定时晨报机器人](https://platform.qianwenai.com/docs/agent-infra/managed-agents/best-practices/production.md): 把 Managed Agents 接入生产：MCP 工具集接入、配置注入（会话环境变量与 Vault 密钥库）、定时任务（Deployment）触发、人工审核（HITL）与资源生命周期管理，示例统一用 curl。
- [进阶：密钥库安全注入与出网网关](https://platform.qianwenai.com/docs/agent-infra/managed-agents/best-practices/credential-security.md): Vault 密钥库的占位符注入模型、allowed_hosts 出口白名单、出网网关的 Authorization 头替换行为，以及会话环境变量与密钥库的选型分层。
- [进阶：提示词版本管理与回滚](https://platform.qianwenai.com/docs/agent-infra/managed-agents/best-practices/prompt-versioning.md): Agent 版本机制、标注测试集评测、Session 版本锁定语义与灰度回滚的做法，把提示词从应用代码剥离为服务端可版本化的资源。
- [进阶：Webhook 事件通知](https://platform.qianwenai.com/docs/agent-infra/managed-agents/best-practices/webhook-notifications.md): 把「事件发生」（会话跑完、部署执行结束、资源变更）变成一次主动的 HTTP 推送：接收端工程、验签、投递语义与重试禁用规则的完整实践。

## MCP

- [MCP 简介](https://platform.qianwenai.com/docs/agent-infra/mcp/introduction.md): 模型上下文协议（Model Context Protocol, MCP）旨在搭建大模型和外部工具之间的信息传递通道。通过 MCP 协议，开发者不用为每个外部工具编写复杂的接口，千问AI平台的智能体也能够接入海量第三方工具。
- [MCP 商店服务](https://platform.qianwenai.com/docs/agent-infra/mcp/official-services.md): 千问AI平台 MCP 商店提供的 MCP 服务所有用户可见，均为 One Key MCP：无需开通，用千问AI平台 API Key 直接鉴权。支持挂载到 Managed Agent 由智能体自主调用，也支持通过外部调用集成至第三方应用或项目中。
- [自定义 MCP 服务](https://platform.qianwenai.com/docs/agent-infra/mcp/custom-services.md): 除官方 MCP 服务外，千问AI平台还支持以下三种自定义 MCP 服务部署方式：使用脚本部署、从 AI 网关导入、从阿里云 OpenAPI 导入。
- [外部调用](https://platform.qianwenai.com/docs/agent-infra/mcp/external-invocation.md): 千问AI平台提供了全周期 MCP 服务，既支持挂载到 Managed Agent 由智能体自主调用，也支持通过外部调用集成至第三方应用或个人项目。
- [常见问题](https://platform.qianwenai.com/docs/agent-infra/mcp/faq.md): 您可以查阅有关 MCP 协议和 MCP 服务的常见问题。

- [使用 Browser Use Sandbox](https://platform.qianwenai.com/docs/agent-infra/sandbox/best-practice-browser-use.md): 面向网页自动化类 Agent 的最佳实践：基于浏览器镜像创建模版，通过 CDP 连接 Puppeteer、Playwright 或 BrowserUse，完成网页访问、交互、截图与结果归档。
- [使用 AIO Sandbox](https://platform.qianwenai.com/docs/agent-infra/sandbox/best-practice-aio.md): 面向“浏览器自动化 + 代码执行 + 文件处理”连续任务的最佳实践：基于全能型镜像创建模版，在同一沙箱中完成网页访问、截图、下载、数据清洗与结果导出。

- [HappyOyster 概述](https://platform.qianwenai.com/docs/api-reference/world-model/happyoyster-overview.md): HappyOyster 是实时交互的开放式世界模型。输入一段自然语言 Prompt 和一张首帧图，即可生成一个可实时演绎、探索、互动的数字世界，输出为可进房的实时视频流。适用于互动剧、影视预演、AI 陪伴、可玩世界等场景。
- [快速开始](https://platform.qianwenai.com/docs/api-reference/world-model/happyoyster-quick-start.md): 完成 HappyOyster 端到端接入：鉴权、服务端 Open API、客户端 SDK、Demo。
- [获取鉴权凭证](https://platform.qianwenai.com/docs/api-reference/world-model/happyoyster-auth-setup.md): 获取 HappyOyster 服务端与客户端所需的鉴权凭证：API Host、主 API Key、临时 API Key、ticket。
- [接入流程](https://platform.qianwenai.com/docs/api-reference/world-model/happyoyster-integration-flow.md): 服务端调用 HappyOyster Open API 准备世界与产物导出，客户端 SDK 完成 RTC 建连与实时互动。
- [下载 SDK 与 Demo](https://platform.qianwenai.com/docs/api-reference/world-model/happyoyster-sdk-and-demo.md): 下载 HappyOyster 各端客户端 SDK 与服务端 Demo 参考实现。
- [客户端SDK](https://platform.qianwenai.com/docs/api-reference/world-model/happyoyster-client-sdk.md): HappyOyster 客户端 SDK 文档索引，覆盖 Android、iOS 与 Web 三个平台的接入指南与 API 参考。
- [Android SDK](https://platform.qianwenai.com/docs/api-reference/world-model/happyoyster-android-sdk.md): HappyOyster Android SDK 文档索引，包含接入指南、API 参考与 Playground 体验指南。
- [HappyOyster Android SDK 接入指南](https://platform.qianwenai.com/docs/api-reference/world-model/happyoyster-android-sdk-integration-guide.md): 本文面向集成方 Android 开发者，覆盖安装、鉴权、完整接入流程、事件处理与最佳实践，说明如何稳定接入 HappyOyster Android SDK。
- [HappyOyster Android SDK API参考](https://platform.qianwenai.com/docs/api-reference/world-model/happyoyster-android-sdk-api-reference.md): HappyOyster Android SDK 入口为单例对象 HappyOyster ，除 initialize 、 updateToken 、 attachVideo 、 sendCommand 外，业务方法均为 suspend ，失败时抛出 SDKError 。
- [Happy Oyster Android Playground 体验指南](https://platform.qianwenai.com/docs/api-reference/world-model/happyoyster-android-playground-guide.md): 本文帮助国内合作方快速了解 Happy Oyster Android Playground：如何安装、登录，并走完一次完整的产品体验。

- [HappyOyster iOS SDK 接入指南](https://platform.qianwenai.com/docs/api-reference/world-model/happyoyster-ios-sdk-integration-guide.md): 本文是 iOS 集成方的最短上手路径：从初始化，到画面出来，到发送控制指令，再到结束体验。完整的方法签名、字段、错误码以 iOS SDK API Reference 为准。
- [HappyOyster iOS SDK API参考](https://platform.qianwenai.com/docs/api-reference/world-model/happyoyster-ios-sdk-api-reference.md): HappyOyster iOS SDK 入口为进程级单例 HappyOysterEngine.shared ，业务方法均为 async throws ，失败时抛出 OysterSDKError 。一次体验由 OysterTravel 句柄承载，支持 UIKit 与 SwiftUI。
- [Web SDK](https://platform.qianwenai.com/docs/api-reference/world-model/happyoyster-web-sdk.md): HappyOyster Web SDK 文档索引，包含接入指南与 API 参考。
- [HappyOyster Web SDK 接入指南](https://platform.qianwenai.com/docs/api-reference/world-model/happyoyster-web-sdk-integration-guide.md): 本文面向前端 / 全栈开发者，说明如何在生产环境中稳定接入 HappyOyster Web SDK 。
- [HappyOyster Web SDK API参考](https://platform.qianwenai.com/docs/api-reference/world-model/happyoyster-web-sdk-api-reference.md): HappyOysterEngine 负责配置 Open Platform host 与模型、更新千问AI平台临时 API Key token，并创建 Travel 会话。 Travel 是 createTravel() 返回的会话对象，调用 travel.start() 后才会进入并启动会话。
- [HappyOyster Adventure Open API参考](https://platform.qianwenai.com/docs/api-reference/world-model/happyoyster-adventure-openapi-reference.md)
- [HappyOyster-Adventure-创建World API参考](https://platform.qianwenai.com/docs/api-reference/world-model/adventure/create-world.md): 创建一个世界探索 World。使用自然语言 Prompt 和必填首帧图创建 World，接口立即返回加密 World ID，World 在后台异步构建，客户端轮询构建进度直至完成。
- [HappyOyster-Adventure-查询World构建状态 API参考](https://platform.qianwenai.com/docs/api-reference/world-model/adventure/query-world-build-status.md): 查询 Adventure World 的构建进度。接口返回加密 World ID、构建状态和首帧 URL，客户端轮询直至 World 进入 ready。
- [HappyOyster-Adventure-获取体验凭证 API参考](https://platform.qianwenai.com/docs/api-reference/world-model/adventure/get-travel-credential.md): 三方服务端使用主 API Key 换取短时效、一次性的 ticket，再将其安全下发给客户端。此接口只校验 World 归属、状态与规格，不创建 Travel。
- [HappyOyster-Adventure-客户端进入房间 API参考](https://platform.qianwenai.com/docs/api-reference/world-model/adventure/enter-travel.md): 客户端使用 ticket 创建实际 Travel，并获取 RTC 入会配置和 Adventure 能力版本。maxExperienceTimeSec 仅在 Adventure 模型中生效。
- [HappyOyster-Adventure-查询Travel状态 API参考](https://platform.qianwenai.com/docs/api-reference/world-model/adventure/query-travel-status.md): 查询 Adventure Travel 生命周期、服务端推流状态和当前世界的动作池，也可同时上报客户端拉流或播放心跳。
- [HappyOyster-Adventure-结束Travel API参考](https://platform.qianwenai.com/docs/api-reference/world-model/adventure/end-travel.md): 主动结束 Adventure Travel。正常结束后进入 completed；无推流超时结束时进入 failed，且不生成回放产物。达到 maxExperienceTimeSec 时服务端也会自动结束。
- [HappyOyster-Adventure-查询World详情 API参考](https://platform.qianwenai.com/docs/api-reference/world-model/adventure/query-world-detail.md): 查询单个 Adventure World 的完整元数据和可回显创建参数。构建进度轮询请使用查询World构建状态接口。
- [HappyOyster-Adventure-查询World列表 API参考](https://platform.qianwenai.com/docs/api-reference/world-model/adventure/query-world-list.md): 分页查询当前千问AI平台账号名下的 Adventure World。接口自动按模型隔离，不会返回 Directing 或 Acting World。
- [HappyOyster-Adventure-删除World API参考](https://platform.qianwenai.com/docs/api-reference/world-model/adventure/delete-world.md): 删除当前千问AI平台账号名下的 Adventure World。同账号下 World 已不存在时幂等返回 deleted=false。
- [HappyOyster-Adventure-查询Travel列表 API参考](https://platform.qianwenai.com/docs/api-reference/world-model/adventure/query-travel-list.md): 分页查询当前千问AI平台账号名下的 Adventure Travel，可按状态或关联 World 筛选。
- [HappyOyster-Adventure-查询Travel产物 API参考](https://platform.qianwenai.com/docs/api-reference/world-model/adventure/query-travel-artifacts.md): 查询已完成 Adventure Travel 的录制原片和三个合成变体。对外交付推荐使用 withInstructionAndWatermark。
- [HappyOyster 错误码](https://platform.qianwenai.com/docs/api-reference/world-model/happyoyster-error-code.md): HappyOyster Open API 响应结构与错误码说明，包括业务码、典型场景与处理建议。
