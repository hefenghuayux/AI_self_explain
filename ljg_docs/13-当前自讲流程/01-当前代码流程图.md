# 当前代码中的自讲流程

本文按当前工作区代码整理，只描述流程走向。流程判断以 `backend/app/rules/` 和 `backend/app/repositories/sessions.py` 为准，提示词只负责评价或生成内容。

## 主自讲流程

```mermaid
flowchart TD
    START["创建或恢复会话"] --> CHOICE{"学生初始选择"}
    CHOICE -- "会" --> CAPTURE
    CHOICE -- "不会 / 有疑问" --> HELP_ENTRY["进入主动求助或疑问流程"]

    CAPTURE["编辑自讲内容<br/>文本输入或语音转写"] --> SUBMIT["提交自讲"]
    SUBMIT --> EVAL["AI 评价本次自讲"]
    EVAL --> VALID["校验评价输出"]
    VALID --> DECIDE{"后端决定教学动作"}

    DECIDE -- "正确且完整" --> COMPLETE
    DECIDE -- "没有进展" --> HINT["给出提示<br/>计入支持次数"]
    DECIDE -- "有进展但有错误" --> CORRECTION["给出纠错<br/>计入支持次数"]
    DECIDE -- "有进展但不完整" --> QUESTION["给出聚焦问题<br/>不计支持"]

    DECIDE -.->|同步更新| PROGRESS["更新连续无进展计数"]

    HINT --> LIMIT
    CORRECTION --> LIMIT
    QUESTION --> TEACH

    LIMIT{"本轮支持次数达到上限？<br/>第 1 轮：6<br/>第 2 轮：3"}
    LIMIT -- "否" --> TEACH
    LIMIT -- "是" --> SOLUTION

    TEACH["AI 生成教学内容"] --> SAVE_SUPPORT["保存支持内容并更新计数"]
    SAVE_SUPPORT --> HAS_QUESTION{"是否包含子问题？"}
    HAS_QUESTION -- "是" --> WAIT_GUIDED["转入子问题作答流程"]
    HAS_QUESTION -- "否" --> WAIT_ACTION

    COMPLETE["学习成功终态<br/>记录完成方式"]

    SOLUTION["达到支持上限<br/>不发送临界那次支持<br/>展示完整解析"] --> ROUND{"当前轮次"}
    ROUND -- "第 1 轮" --> UNDERSTAND["学生确认已理解"]
    UNDERSTAND --> ROUND2["进入第 2 轮<br/>重置本轮计数"]
    ROUND2 --> CAPTURE
    ROUND -- "第 2 轮" --> STOPPED["非成功终态"]

    WAIT_ACTION["等待学生操作"] -- "继续自讲" --> CAPTURE
    WAIT_ACTION -- "请求提示 / 提出疑问" --> HELP_ENTRY

    classDef student fill:#dae8fc,stroke:#6c8ebf,color:#1f2937;
    classDef ai fill:#e1d5e7,stroke:#9673a6,color:#1f2937;
    classDef backend fill:#d5e8d4,stroke:#82b366,color:#1f2937;
    classDef decision fill:#fff2cc,stroke:#d6b656,color:#1f2937;
    classDef warning fill:#f8cecc,stroke:#b85450,color:#1f2937;
    classDef terminal fill:#e2f0d9,stroke:#3f8f4f,color:#1f2937;

    class CHOICE,CAPTURE,SUBMIT,WAIT_ACTION,UNDERSTAND student;
    class EVAL,TEACH ai;
    class START,VALID,HINT,CORRECTION,QUESTION,PROGRESS,SAVE_SUPPORT,WAIT_GUIDED,ROUND2 backend;
    class DECIDE,LIMIT,HAS_QUESTION,ROUND decision;
    class SOLUTION,STOPPED warning;
    class COMPLETE terminal;
```

## 主动求助、疑问和子问题作答

```mermaid
flowchart TD
    ENTRY["学生主动操作"] --> SUPPORT["请求提示"]
    ENTRY --> DOUBT["提出疑问"]

    SUPPORT --> LIMIT{"下一次支持<br/>是否达到本轮上限？"}
    DOUBT --> GENERATE

    LIMIT -- "是" --> FULL["展示完整解析"]
    LIMIT -- "否" --> GENERATE

    GENERATE["AI 生成疑问支持"] --> ACTION{"支持类型"}
    ACTION -- "拒绝完整答案" --> REFUSE["记录拒绝<br/>不计支持"]
    ACTION -- "直接回答疑问" --> DIRECT_LIMIT{"写入支持前<br/>是否达到上限？"}
    ACTION -- "给出子问题" --> GUIDED_LIMIT{"写入支持前<br/>是否达到上限？"}
    DIRECT_LIMIT -- "是" --> FULL
    GUIDED_LIMIT -- "是" --> FULL
    DIRECT_LIMIT -- "否" --> DIRECT["直接回答疑问<br/>计入支持次数"]
    GUIDED_LIMIT -- "否" --> QUESTIONS["展示子问题<br/>计入支持次数<br/>等待作答"]

    QUESTIONS --> ANSWERS["学生提交子问题答案<br/>允许分批提交"]
    ANSWERS --> ALL{"所有子问题都已回答？"}
    ALL -- "否" --> ANSWERS
    ALL -- "是" --> ASSESS["AI 评估子问题作答"]
    ASSESS --> SAVE["写回评估结果<br/>不再增加支持次数"]

    classDef student fill:#dae8fc,stroke:#6c8ebf,color:#1f2937;
    classDef ai fill:#e1d5e7,stroke:#9673a6,color:#1f2937;
    classDef backend fill:#d5e8d4,stroke:#82b366,color:#1f2937;
    classDef decision fill:#fff2cc,stroke:#d6b656,color:#1f2937;
    classDef warning fill:#f8cecc,stroke:#b85450,color:#1f2937;

    class ENTRY,SUPPORT,DOUBT,ANSWERS student;
    class GENERATE,ASSESS ai;
    class DIRECT,QUESTIONS,SAVE backend;
    class LIMIT,ACTION,DIRECT_LIMIT,GUIDED_LIMIT,ALL decision;
    class REFUSE,FULL warning;
```

## 暂停与恢复

暂停会保存当前阶段，恢复后回到该阶段。允许暂停的阶段：

- `WAIT_INITIAL_CHOICE`
- `CAPTURING_INPUT`
- `WAIT_STUDENT_ACTION`
- `SHOWING_FULL_SOLUTION`

`AI_EVALUATING`、`TRANSCRIBING` 和 `WAIT_GUIDED_ANSWERS` 不能直接暂停。

## 代码依据

- `backend/app/api/sessions.py`：学生操作入口和调用顺序。
- `backend/app/rules/teaching_decision.py`：评价结果到教学动作的确定性映射。
- `backend/app/rules/teaching_cycle.py`：支持上限和完成类型。
- `backend/app/rules/session_lifecycle.py`：状态、流程阶段和暂停规则。
- `backend/app/schemas/ai_evaluation.py`：评价输出字段及关系校验。
- `backend/app/schemas/teaching.py`：教学输入输出契约。
- `backend/app/schemas/support.py`：疑问支持和子问题作答契约。
- `backend/app/repositories/sessions.py`：计数、状态变更和数据落库。
