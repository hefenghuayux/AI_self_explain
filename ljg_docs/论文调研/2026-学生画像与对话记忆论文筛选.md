
# 2026 年学生画像与对话记忆论文筛选

> 检索截止：2026-09-16。候选仅保留 2026 年首次公开或正式发表的论文。预印本、在投论文与同行评审论文分别标注，不能把预印本结论视为已经同行验证。

## 一、先给项目结论

对“AI 自讲”而言，学生画像不应是一段不断覆盖的 Markdown 总结，也不应直接等同于聊天历史的向量检索。更稳妥的结构是三层：

1. **权威证据层**：数据库保存学生确认文本、合法结构化评价、实际发送的支持、学生后续表现和状态事件，记录不可变来源。
2. **确定性画像投影层**：按学生、知识点、认知过程和教学策略聚合可重建状态；规则负责计数、时间衰减、冲突、晋级、撤销和可见范围。
3. **AI 解释层**：大模型从有界证据中抽取候选错因、行为模式和证据片段，生成可读总结；总结不是权威事实，必须携带来源、版本、有效期，并允许重算。

数据库适合承载运行数据和画像投影。Markdown 适合保存设计说明、人工审核报告或导出快照，不适合作为在线画像主存储：它缺少事务、索引、权限、并发更新、字段约束、来源追溯和可靠重算能力。

## 二、建议的学生画像结构

### 1. 画像内容

| 画像域         | 建议字段                                                             | 主要证据                       | 主要用途                     |
| -------------- | -------------------------------------------------------------------- | ------------------------------ | ---------------------------- |
| 知识状态       | 知识点、独立完成、支持后完成、明确错误、迁移题表现、最近证据时间     | 终态会话、合法评价、题目知识点 | 推荐题目、复习排序、学习规划 |
| 错因与薄弱环节 | 错因类型、涉及步骤、证据原文、出现次数、最近一次、是否被后续证据推翻 | 自讲文本、错误证据、后续修正   | 后续追问重点、变式题选择     |
| 自讲过程能力   | 条件复述、目标识别、知识调用、推理链、关系解释、验证检查、反思修正   | 评分点、过程标注、对话转移     | 决定下一轮追问哪一步         |
| 教学响应       | 提示、聚焦追问、纠错、例子、反问等策略后的进步幅度                   | 支持事件与后续尝试配对         | 选择更可能有效的教学动作     |
| 交互习惯       | 平均长度、修订频率、主动提问、卡顿位置、重复表述                     | 多轮对话事件                   | 调整节奏和输出长度           |
| 明示偏好       | 学生主动选择的详略、表达方式、是否需要图示                           | 学生明确设置                   | 个性化表达，可由学生修改     |
| 可信度元数据   | 来源、证据数量、跨题覆盖、置信区间、算法版本、有效期、更新时间       | 系统生成                       | 防止把一次表现固化成人格标签 |

“粗心”“不自信”“逻辑差”等人格化结论不宜直接进入画像。应保存可观察事实，例如“最近 4 次代数自讲中有 3 次未执行结果检验”，并保留题目、文本片段和时间。

### 2. 推荐的数据结构

#### `student_profile_evidence`

- `id`
- `student_id`
- `session_id`、`attempt_id`、`evaluation_id`
- `knowledge_point_id`
- `dimension`：知识、错因、过程、教学响应、交互习惯、明示偏好
- `observation_type`
- `value_json`
- `evidence_quote`
- `polarity`：支持、反驳、修正
- `source_type`
- `observed_at`
- `extractor_version`
- `validation_status`

#### `student_profile_state`

- `student_id + scope_type + scope_id + dimension + trait_key` 唯一
- `state_json`
- `evidence_count`
- `cross_task_count`
- `confidence_level`
- `first_observed_at`、`last_observed_at`
- `superseded_by`
- `projection_version`
- `source_watermark`

#### `student_profile_summary`

- `student_id`
- `summary_type`
- `summary_text`
- `source_evidence_ids`
- `generated_at`
- `model_id`、`prompt_version`
- `expires_at`
- `review_status`

原始事件和 `student_profile_evidence` 保证可追溯；`student_profile_state` 是可重算投影；`student_profile_summary` 只承担教师和模型可读表达。

### 3. 写入与更新触发

1. 学生最终确认文本且评价通过结构、关系和原文引用校验后，写入本轮候选证据。
2. 支持事件实际发送，并出现后续回答或终态结果后，写入“策略—响应”配对证据。
3. 会话进入有效终态后，重算对应学生与知识点投影；草稿、ASR 候选、失败模型输出和人工未决记录不能晋级画像。
4. 单次观察只能形成“候选模式”；跨至少两个题目或多个会话重复出现后，才晋级为稳定画像。具体阈值必须通过离线数据校准，不能由大模型临场决定。
5. 新证据与旧画像冲突时保留两者及时间关系，通过确定性规则降权、撤销或标记已修正，不覆盖历史。
6. 画像被用于推荐、学习计划或教学提示前，检查版本、水位线、有效期、权限和来源数量；过期或证据不足时返回空画像。

### 4. 规则与大模型的分工

| 环节     | 大模型                           | 确定性代码                               |
| -------- | -------------------------------- | ---------------------------------------- |
| 错因抽取 | 返回候选类型、证据原文、涉及步骤 | 校验枚举、原文引用、题目范围和字段关系   |
| 画像晋级 | 不决定                           | 按次数、跨题覆盖、时效和冲突规则决定     |
| 状态更新 | 提供候选解释                     | 计数、去重、衰减、撤销、版本和权限       |
| 召回     | 可对候选证据做语义排序           | 限定本人、知识点、时间窗、预算和允许字段 |
| 教学使用 | 根据允许动作生成话术             | 决定动作、帮助上限、题目选择和流程状态   |
| 总结     | 生成可读摘要                     | 保存来源、过期时间，支持重算和人工纠正   |

推荐把画像当作“带证据、会变化的假设集合”，避免生成单一且永久的学生描述。

### 最终推荐 10 篇

#### 1. Beyond ID Embeddings: Process-Grounded Language Modeling for Cognitive Diagnosis

- 主分类：教育 AI / 学生认知诊断
- 类型与状态：EMNLP 2026 已接收；arXiv 预印本页面
- 作者与日期：Minghang Liu 等，2026-09-11
- 原始链接：[arXiv:2609.12403](https://arxiv.org/abs/2609.12403)
- 研究证据：提出 PLCD，用概念 schema、认知过程图、目标相关历史回答检索和语言到认知映射预测学生表现；包含性能、消融、冷启动、稀疏性、记忆机制和认知落地分析。
- 推荐理由：这是最接近“从自讲过程构建可计算学生画像”的论文。它提示画像应同时包含知识点状态、过程结构和目标相关历史证据，不能只保留学生 ID 向量或自由文本总结。对新题、新概念和缺失标注的冷启动分析也直接对应本项目题库持续扩展场景。
- 局限与采用风险：模型复杂度较高，面向平台级认知诊断；项目早期可吸收 schema、过程图和目标相关召回思路，不宜直接复制完整训练架构。
- 热度数据：公开页面未显示具体热度数据。

#### 2. StudentSim: Training LLM-based Student Simulators

- 主分类：教育 AI / 学生行为模型
- 类型与状态：预印本，未见同行评审状态
- 作者与日期：Ke Yang 等，2026-09-01
- 原始链接：[arXiv:2609.01591](https://arxiv.org/abs/2609.01591)；[代码](https://github.com/microsoft/StudentSim)
- 研究证据：在国际象棋、二语写作和数学三个领域、60 名学生上评估；同时测量行为拟合度与接受指导后的响应度，并用消融分析两阶段训练。
- 推荐理由：它把学生模型的目标从“预测答对答错”扩展为“复现学生当前行为并预测其接受某种指导后的变化”。这正好支持本项目把画像用于选择追问、提示和纠错策略，也提醒评测画像时必须同时检查行为真实性和教学响应预测。
- 局限与采用风险：个体专门化成本高，模拟学生仍是代理评价，不能代替真实学习效果；当前项目更适合采用其评测维度，而不是立即训练每个学生的模拟器。
- 热度数据：公开页面未显示具体热度数据。

#### 3. Penny: Transition Network Analysis of Learner-Chatbot Interactions in Scaffolded EFL Writing

- 主分类：教育 AI / 对话行为分析
- 类型与状态：同行评审书籍章节
- 作者与日期：Steve Woollaston、Brendan Flanagan、Yuko Toyokawa、Hiroaki Ogata，2026
- 原始链接：[DOI:10.1007/978-3-032-34157-0_13](https://doi.org/10.1007/978-3-032-34157-0_13)；[arXiv:2607.14575](https://arxiv.org/abs/2607.14575)
- 研究证据：分析 4,500 多个写作会话和 21,000 次交互，使用转移网络识别“反馈—修订”和“持续对话”两类行为循环，并比较不同熟练度学生。
- 推荐理由：它提供了从事件序列而非单轮标签构建画像的范例。项目可以把“AI 支持后是否修正、是否继续解释、是否反复进入同一错误环”做成确定性序列特征，用于刻画教学响应和自讲习惯。
- 局限与采用风险：场景是日本 EFL 写作，行为环不能直接迁移到数学或其他学科；论文中的部分大规模分类依赖 LLM，也需要人工抽样校验。
- 热度数据：公开页面未显示具体热度数据。

#### 4. TACT: Taxonomy-Aligned Post-Training for Pedagogically Adaptive English Tutoring

- 主分类：教育 Agent / 教学策略选择
- 类型与状态：预印本，未见正式接收信息
- 作者与日期：Dongjie Yang 等，2026-08-04
- 原始链接：[arXiv:2608.03952](https://arxiv.org/abs/2608.03952)
- 研究证据：从 260 段真实一对一英语教学对话构建 32,379 条标注，定义 13 类教师策略和学生行为 taxonomy；在 78 个真实教学上下文和 50 名学习者盲测中评估，并报告外部教育基准。
- 推荐理由：它回答“画像怎么使用”：先识别当前学生行为及状态，再映射到有限教学策略。项目可以借鉴其“学生动作—状态—教师策略”契约，把画像限制为教学决策所需的可操作字段，避免收集与教学无关的个性信息。
- 局限与采用风险：主要是 ESL，且采用后训练；本项目应优先复用 taxonomy 和评测方法，不必因此引入模型微调。

#### 5. Retrieval-augmented generation for pedagogically aware educational AI: an expert-rated comparison of a prompt-only LLM tutor and an integrated, learner-state-aware RAG tutor

- 主分类：教育 Agent / 学习者状态感知 RAG
- 类型与状态：Frontiers in Education 同行评审原创研究
- 作者与日期：Jude A. Adenuga，2026-08-17
- 原始链接：[DOI:10.3389/feduc.2026.1896839](https://doi.org/10.3389/feduc.2026.1896839)
- 研究证据：同一 Gemini 2.5 Flash 下比较提示词基线与“课程语料 + 学习者状态 + 教学策略”的集成 RAG；24 个两轮代数任务，由 8 名专家盲评。集成方案教学质量评分更高，但无依据内容从 1/192 增至 13/192。
- 推荐理由：它给出一条可直接落地的运行链：检索课程证据、读取有限学习者状态、由规则选择响应模式、组装提示并记录审计。更重要的是，它证明加入 RAG 和画像也可能增加证据边界泄漏和无依据内容，因此画像召回不能绕过输出校验。
- 局限与采用风险：没有真实学生和学习结果；多个组件同时变化，无法区分 RAG、状态跟踪和策略规则各自贡献；语料与 24 道题高度匹配。
- 热度数据：公开页面未显示具体热度数据。

#### 6. PGMem: Tightly Coupled Persona-Memory Graph for Lifelong Personalized Agents

- 主分类：Memory / 个性画像证据图
- 类型与状态：EMNLP 2026 主会已接收
- 作者与日期：Wonjun Choi、Yerim Kim、Yukyung Lee、Susik Yoon，2026-08-03
- 原始链接：[arXiv:2608.01708](https://arxiv.org/abs/2608.01708)；[代码](https://github.com/wonjunchoi23/pgmem/)
- 研究证据：将事件节点与状态、特质节点通过有类型的来源和证据边连接；在三个基准、小模型骨干上与摘要、画像感知、图结构和 agentic memory 基线比较，包含消融、人类验证和效率分析。
- 推荐理由：这是设计学生画像数据结构最直接的参考。每个画像结论都连接支持、反驳或修正它的会话证据，召回时按证据有效性排序。项目可把“错因/习惯”作为可变状态节点，而不是无来源的固定标签。
- 局限与采用风险：实验限于合成长期对话，论文也承认真实长期画像演化、图规模和删除权尚未充分验证；第一版可先用关系表实现证据边，无需立即部署图数据库。

#### 7. MemSIF: From Structured Interactions to Dual-Track Fact Memory for LLM Agents

- 主分类：Memory / 长期对话结构化
- 类型与状态：预印本，已投稿 AAAI 2027
- 作者与日期：YuFei Luo、Xiucheng Xu、Zhen Yang，2026-08-03
- 原始链接：[arXiv:2608.01742](https://arxiv.org/abs/2608.01742)；[代码](https://github.com/luoyufeihaha/MemSIF)
- 研究证据：区分主题片段、跨时事件轨迹、稳定 CoreFact 与按查询形成并逐步晋级的 ActiveFact；在 LoCoMo、LongMemEval-S 和五个骨干模型上比较，包含消融、机制和效率分析。
- 推荐理由：它对触发条件尤其有价值。稳定事实可以按 schema 在写入时形成；用途尚不明确的信息先保留在结构化交互中，只有被多源支持或反复召回后再晋级。对应项目就是“单次错因是候选，跨题重复后才成为稳定画像”。
- 局限与采用风险：仍是通用对话记忆基准，准确问答不等于学习诊断有效；晋级阈值必须用教育数据重新校准。

#### 8. CueMem: Cue-Guided Context Reconstruction for Long-Term Conversational Memory

- 主分类：Context Engineering / 可追溯召回
- 类型与状态：预印本，未见同行评审状态
- 作者与日期：Changjian Wang 等，2026-09-11
- 原始链接：[arXiv:2609.12354](https://arxiv.org/abs/2609.12354)
- 研究证据：把抽取出的记忆记录当作检索线索，并链接回原始对话轮；召回后从时间和语义关系图重建紧凑证据上下文。在 LoCoMo 与 LongMemEval 上与长期记忆基线比较，包含消融与效率分析。
- 推荐理由：它支持“画像不是最终证据”的设计。后续教学模型先用画像条目定位来源，再把少量原始学生表达和相关上下文放进提示，能同时保留压缩效率和归因依据。
- 局限与采用风险：依赖对话图和线索抽取质量；教育场景还需防止把早期错误原文反复暴露给模型造成锚定。

#### 9. Verifiable Memory: Learning Unified Memory Management with Local and Global Verifiers for Large Language Model Agents

- 主分类：Agent Harness / 可验证记忆管理
- 类型与状态：预印本，未见同行评审状态
- 作者与日期：Xiaolong Sun、Qichao Wang、Hangyu Li、Liang Chen，2026-08-04
- 原始链接：[arXiv:2608.03137](https://arxiv.org/abs/2608.03137)；[代码](https://github.com/Sun-SYSU-24/VerMem)
- 研究证据：明确区分长期记忆、活动上下文和情节历史，用新增、修改、软删除、检索、过滤、摘要、恢复七种原子操作；用局部状态转换验证器和全局一致性验证器训练，在五个基准、两个骨干和受控 token 预算下评估。
- 推荐理由：它强化了本项目的“AI 提议、代码验证”边界。画像更新应拆成有限原子操作，并对每次转换校验来源、字段、权限和一致性；会话终态再做全局复核，避免一次模型输出直接覆盖学生档案。
- 局限与采用风险：训练式统一策略明显重于当前 Demo；适合借鉴操作集合和验证机制，不建议第一版引入强化学习记忆控制器。

#### 10. Retain or Consolidate? Budget-Dependent Operator Selection for Language Agent Memory

- 主分类：Memory / 上下文预算管理
- 类型与状态：预印本，未见同行评审状态
- 作者与日期：Qingcan Kang 等，2026-07-20，2026-07-21 更新 v2
- 原始链接：[arXiv:2607.17545](https://arxiv.org/abs/2607.17545)
- 研究证据：形式化比较保留原始记录与 Merge、Abstract、Rewrite 三类压缩操作；在 LongMemEval 和 LoCoMo 上展示随 token 预算变化的交叉点，并做跨数据集复制与稳健性分析。
- 推荐理由：它为“什么时候存原文，什么时候做 AI 总结”提供了明确原则：存储层始终保留原始记录；推理上下文预算紧时才生成合并或抽象视图，预算宽松且证据能装下时优先原文。画像摘要应是可替换视图，不能覆盖来源。
- 局限与采用风险：核心实验是通用问答记忆，部分分析基于受控证据条件；对教育任务还要单独测量错因遗漏、教学误导和学生隐私成本。

- 状态与链接：CSEDU 2026 会议论文，[DOI:10.5220/0015046100004021](https://doi.org/10.5220/0015046100004021)
- 方法：把学习目标、学习周期和微目标建模为 epic、sprint、user story 和 definition of done；在编程课 Telegram 多 Agent 聊天机器人中做 16 人探索性研究。
- 淘汰理由：过程型 learner model 很贴题，但样本只有 16 人，主要是主观可行性结果，缺少受控对照和学习成效；作为产品结构灵感有价值，证据强度低于入选论文。

#### 12. A Prompt-Engineering Approach to Develop Scalable, Flexible, and Real-Time Hybrid Micro-Level Personalization in a General Purpose AI Teaching Assistant

- 状态与链接：IAAI 2027 论文说明，当前为预印本，[arXiv:2609.03402](https://arxiv.org/abs/2609.03402)
- 方法：用自评、抽象偏好、详略偏好、感知取向、信息处理风格和理解水平组合 96 类学习者画像，生成 2,910 个响应；人类研究 5 人。
- 淘汰理由：提供了提示词画像注入范例，但 96 类笛卡尔积存在过度离散化风险，人类样本仅 5 人，主要证明输出会变化，没有证明学习效果改善。学习风格类字段也容易固化未经充分验证的标签。

#### 13. EvalConvoLearn: An Open-Source Framework for Evaluating Grounded Learner Simulations in Tutoring Conversations

- 状态与链接：Festival of Learning 2026 工作坊海报/预印本，[arXiv:2608.07497](https://arxiv.org/abs/2608.07497)；[代码](https://github.com/RenaissancePhilanthropy/EvalConvoLearn)
- 方法：从技能掌握结果和对话质量两条轴评估学习者模拟，在 Eedi 辅导数据集上演示并做上下文消融。
- 淘汰理由：评测框架方向正确且代码开放，但当前证据集中于单一数据集和两个模拟器，发表形态与实验广度弱于 StudentSim；可作为补充实现参考，不进入前十。

#### 14. Graph-Based Personalized Memory for LLM Agents: Representation, Evolution, Retrieval, and Evaluation

- 状态与链接：ICKG 2026 已接收综述，[arXiv:2609.08599](https://arxiv.org/abs/2609.08599)
- 方法：按表示、演化、检索和评估梳理图式个性化记忆。
- 淘汰理由：与学生画像结构高度相关，也有正式接收状态，但它是二手综述，没有直接实验。前十已包含 PGMem、MemSIF、CueMem 等可验证的一手方法；若后续要系统设计图谱 schema，这篇应作为首要扩展阅读。

#### 15. AgentMemBench: A Systematic Benchmark for Evaluating Long-Term Memory Management Strategies in Conversational AI Agents

- 状态与链接：预印本，说明已投 Neural Computing and Applications，[arXiv:2608.00009](https://arxiv.org/abs/2608.00009)
- 方法：在 491 个问题轮上统一比较窗口、外部键值、图式情节、压缩摘要和 Web 增强记忆，并报告召回、排序、F1、faithfulness、内存和延迟。
- 淘汰理由：可复现性主张和统一指标有价值，但只使用一个 7B 生成/评判模型，生成与评判共享模型，静态问答和单语数据外部效度有限，绝对 faithfulness 分数也偏低。对本项目的直接指导弱于入选的写入、证据链和教育画像论文。

## 四、如何把十篇论文合成一套实现原则

1. **画像的最小单位是证据，不是总结。** PGMem 和 CueMem 都要求画像结论能回到事件或原始轮次。
2. **画像分稳定状态与候选状态。** MemSIF 的 CoreFact/ActiveFact 可映射为“已确认画像/待观察模式”。
3. **知识画像要过程化。** PLCD 表明只存答对答错不足以支撑迁移和冷启动，应记录学生在哪个认知步骤发生遗漏。
4. **画像必须服务于有限教学动作。** TACT 将学生动作映射到教师策略；规则层决定动作，大模型只生成对应内容。
5. **使用效果要测后续表现。** StudentSim 的行为拟合与指导响应双指标可扩展为：画像是否正确预测学生下一次表现，以及采用画像后是否提升独立完成、迁移和延迟保持。
6. **RAG 需要有界状态和输出校验。** learner-state-aware RAG 的实验显示，更多上下文也可能增加无依据内容和内部痕迹泄漏。
7. **摘要是上下文视图。** Retain or Consolidate 支持按预算选择原文或压缩；存储层不可因摘要而丢失原始证据。
8. **每次记忆操作可验证。** VerMem 的原子操作适合转成后端命令与审计事件。

## 五、建议的第一阶段范围

第一阶段只实现三类画像：

1. 按知识点聚合的完成与错误证据；
2. 按自讲过程步骤记录的遗漏模式；
3. 教学策略与后续进步的配对记录。

暂缓人格、学习风格、情绪特质和自由文本“综合评价”。前者能直接支持题目推荐、追问重点和学习计划，也能从现有会话事实重建；后者容易受到样本少、模型偏见和标签固化影响。

## 六、合理性批判与不足

1. 2026 年论文非常新，很多只是预印本或在投稿，长期复现和引用尚未形成；本报告的“高质量”主要依据实验设计、基线、消融、开放材料和与项目的匹配度。
2. 通用长期记忆基准通常优化问答正确率，不能直接证明学生画像有助于学习。项目必须用延迟独立完成、迁移题、重复提示率和人工纠错率做领域验证。
3. 教育论文常受单学科、小样本或短期实验限制；画像 schema 应保留学科与题型作用域，不能把局部行为泛化为全局学生特征。
4. 图式记忆有良好可解释性，但引入图数据库并非必要条件。早期用关系数据库的证据表和关联表即可验证价值，等查询模式和规模明确后再评估图基础设施。
5. 学生画像会放大隐私和标签固化风险。上线前还需补充学生查看、纠正、撤销、保留期限和敏感属性禁止推断规则。
