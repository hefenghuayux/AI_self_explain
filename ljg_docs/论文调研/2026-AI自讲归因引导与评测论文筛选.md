# 2026 年 AI 自讲归因、引导与评测论文筛选

检索截止：2026-09-16。

本报告只纳入 2026 年首次公开或正式发表的研究。预印本、在投论文和同行评审论文分别标注。筛选优先级依次为：与“学生讲出完整解题依据”的相关度、是否有真实学习者或真实对话、实验设计、基线与消融、能否支持具体产品决策。引用量不能代表这些新论文的质量，因此只把它当作附加信息，不作为入选条件。

## 一、结论先行

现有原因分类有可用的骨架，但还不能直接当作可靠的学生画像。它把“可观察现象”“认知原因”和“不确定状态”放在了同一层：

| 当前类别 | 判断 | 主要问题 |
| --- | --- | --- |
| 表达与输入问题 | 保留，但收紧条件 | 它可能只是 ASR、措辞或信息缺失，未必是认知原因。只有系统已有证据表明思路正确时，才能归到这一类。 |
| 题意理解问题 | 保留 | 对应学生对对象、条件和所求的任务模型错误。 |
| 知识理解与回忆问题 | 建议拆分 | “想不起”和“理解错误”的引导不同：前者需要低提示检索线索，后者需要对比、反例或认知冲突。 |
| 知识应用问题 | 保留 | 对应“知道规则，但不会把题目条件映射到规则”。这是中学数学自讲中很常见、也值得单独处理的一类。 |
| 执行错误 | 保留，但要求前置证据 | 只有学生已经正确建立式子或说明规则，且错误局限在计算、代入、符号或抄写时才能使用。 |
| 原因未明 | 必须进入运行契约 | 证据不足或冲突时应允许暂缓归因。强迫模型五选一会制造伪确定性。 |

建议的最小分类是 6 个具体原因加 1 个不确定状态：

1. 表达或输入问题
2. 题意理解问题
3. 知识提取失败
4. 概念或规则误解
5. 知识应用问题
6. 执行错误
7. 原因未明

这次最重要的改动不应是继续增加标签，而是先让每个标签满足两个条件：一是有可引用的学生证据，二是它会改变下一步帮助。如果两个候选原因最终都要问同一个问题，就没有必要先区分原因。

论文证据也不支持“更细的归因、更强的支架一定更好”。开放自讲能改善某些迁移题的解释质量，但未稳定提升答案正确率；具体化追问并未必优于一般追问；预注册实验甚至发现，自讲对事实记忆没有因果优势。因此，项目的主指标应是学生随后能否独立补出新的有效依据，而不是模型是否产出一个听起来合理的原因标签。

## 二、大模型依据什么判断原因

### 1. 先定位首个断点，再推断原因

模型先输出可观察断点，例如“遗漏了直线与坐标轴交点的求法”“把垂直写成斜率相等”“列式正确但移项符号错误”。只有断点明确后，才推断原因。

推荐的判断顺序：

1. 对照题目、标准解题链和评分点，找到学生解释中的首个错误或缺失步骤。
2. 只读取学生原文、此前独立作答、已发出的提示和后续反应；不能从一次错误推出“粗心”“基础差”等稳定特征。
3. 检查学生是否已经展示了所需知识。展示过正确定义或公式，却没有映射到当前条件，归“知识应用问题”；连定义或适用条件都说错，归“概念或规则误解”。
4. 检查正确结构是否已经建立。结构正确且只有局部运算错，归“执行错误”；结构未建立，不能仅凭结果错误归为执行错误。
5. 若两类原因都符合且会触发不同帮助，先返回“原因未明”，提出一个最小区分问题。若帮助相同，跳过原因区分，直接给帮助。

### 2. 每类原因的证据门槛

| 原因 | 支持证据 | 反证或禁用条件 |
| --- | --- | --- |
| 表达或输入问题 | 方程、图示或后文已经体现正确思路，当前只是省略依据、指代不清或转写异常 | 不能因为答案短就判定；若核心知识没有任何正确证据，应使用其他原因或“原因未明” |
| 题意理解问题 | 漏掉、篡改条件，混淆对象，回答了不同问题，无法说清已知与所求 | 单纯算错不能支持这一类 |
| 知识提取失败 | 学生明确表示想不起，或在低提示检索题上无法给出定义、公式、性质 | 学生给出了错误且稳定的规则时，更像“概念或规则误解” |
| 概念或规则误解 | 学生明确陈述了错误定义、适用条件或因果关系，并在相似处重复使用 | 一次笔误或局部符号错误不足以支持 |
| 知识应用问题 | 能说出所需知识，但不能说明题目条件如何满足该知识，或不会选择、组合方法 | 无法说出知识本身时，先考虑提取失败或误解 |
| 执行错误 | 方法、公式和代入对象均正确，错误局限在计算、符号、抄写或变形 | 建模、选法、条件对应错误不能归入执行错误 |
| 原因未明 | 信息不足、证据互相冲突、多个候选无法区分 | 不能为了填满字段强选最像的一类 |

`judge_reason` 应采用“证据 -> 判断 -> 不确定边界”的短结构，例如：

> 学生正确写出了斜率公式，但没有把 A、B 两点的坐标对应到公式中，说明公式本身已经提取出来；当前卡点更像条件到知识的映射，暂归为知识应用问题。现有文本不足以判断其是否同时混淆了横纵坐标。

建议让模型另外返回 `evidence_spans`，逐字引用学生原文中的依据。`judge_reason` 适合给人看，`evidence_spans` 适合校验和评测。不要把自由文本理由本身当作可信证明。

## 三、归因后的针对性引导

| 原因 | 第一层帮助 | 仍无进展时 | 避免 |
| --- | --- | --- | --- |
| 表达或输入问题 | 指明缺的是哪一种依据，请学生用一句话或一个等式补全 | 给出句式骨架，但不填关键内容 | 把完整答案改写一遍让学生照抄 |
| 题意理解问题 | 请学生只复述相关条件和所求 | 让学生标出对象、数量关系或限制词 | 提前告诉应使用的公式 |
| 知识提取失败 | 给低提示检索线索，如名称、图形特征或公式左侧 | 再给定义框架或一个不含本题数值的例子 | 第一轮直接展示完整公式和本题代入 |
| 概念或规则误解 | 用最小反例或两种情形做区分，请学生预测并解释 | 明确指出冲突，再让学生重述修正后的规则 | 只说“这个概念错了” |
| 知识应用问题 | 问“题目中的哪个条件对应规则的哪个前提，为什么” | 提供一座桥：指出需要检查的条件，不给最终代入 | 再讲一遍概念定义，却不连接本题 |
| 执行错误 | 圈定首次出错的局部，请学生重算或用逆运算、估算核对 | 给检查规则或中间结果边界 | 重讲整道题或贴“粗心”标签 |
| 原因未明 | 问一个能区分候选原因的简答题 | 根据回答重新归因 | 同时询问多个互相依赖的问题 |

一轮可显示 1 至 2 个简答题。两个问题必须针对同一个当前断点，分别提供互补证据，而且第二问不能依赖第一问的答案。例如：

- “垂直的两条非竖直直线，斜率之间有什么关系？”用于检查规则本身。
- “题目中的哪两个量可以用来得到这两条直线的斜率？”用于检查条件映射。

若第一问的答案会直接泄露第二问，就不应同时展示。

## 四、推荐提示词和 Skill 结构

### 1. 诊断提示词骨架

```text
你负责判断学生当前解释的首个断点，并生成最小帮助。原因只是本轮可修正假设，不是学生长期标签。

输入：
- 题目、标准解题链、评分点
- 学生当前确认文本
- 学生此前独立文本
- 已发送的教学内容及学生后续反应
- 后端确定的动作、问题数量上限和禁止泄露内容

按以下顺序处理：
1. 找出首个错误或缺失步骤，写成可观察事实。
2. 引用支持判断的学生原文；没有证据就返回“原因未明”。
3. 在允许原因中选择一个 main_reason。只有当次要原因会影响后续复核时，才返回一个 other_reason。
4. 用一句短话写 judge_reason，说明证据、判断和限制。
5. 只针对 main_reason 生成最小帮助。问题应开放、可回答、不暗示关键答案。
6. 不改变后端给定的状态、计数、阈值和动作；不输出完整解析或后续评分点答案。

判断边界：
- 已正确陈述知识但不会对应题目条件：知识应用问题。
- 明确说错定义或适用条件：概念或规则误解。
- 方法和列式正确，只有局部运算或符号错：执行错误。
- 只因文本短、答案错或一次失误，不能判断稳定原因。
- 证据冲突或不足：原因未明。
```

### 2. 输出契约建议

```json
{
  "first_breakpoint": "首个错误或缺失步骤",
  "main_reason": "允许原因或原因未明",
  "other_reasons": [],
  "evidence_spans": ["学生原文逐字片段"],
  "judge_reason": "简短判断依据和限制",
  "intervention_goal": "本轮要让学生独立补出的内容",
  "content": "最小提示或纠错",
  "questions": [
    {"id": "q1", "question": "简答题"}
  ]
}
```

### 3. 是否值得做成 Skill

值得，但应在标注集和输出契约稳定后再做。Skill 适合固化四类内容：原因判定表、证据门槛、帮助阶梯、泄漏检查。题目内容、学生历史和评分点继续作为运行输入，不应写死在 Skill 中。

第一版 Skill 只需要这些文件：

```text
self-explanation-diagnosis/
  SKILL.md
  references/reason-rubric.md
  references/guidance-ladder.md
  references/evaluation-rubric.md
  examples/annotated-dialogues.jsonl
```

专家可能会质疑：把提示词包装成 Skill 不会自动提高正确率。这个质疑成立。Skill 的价值是版本化和减少提示漂移；有效性仍由盲标数据、对照实验和真实学生结果决定。

## 五、优化策略

### 阶段 1：先建立可审计基线

抽取 20 至 30 道初中数学题，每题 4 至 6 个评分点，覆盖概念、条件映射、计算和证明表达。为每道题构造或收集多轮学生解释，由两名数学教师独立标注：首个断点、可支持的原因、证据片段、允许的帮助和泄漏内容。分歧由第三人裁决。

先比较三个版本：

- A：当前提示词。
- B：增加首个断点、证据片段和“原因未明”。
- C：在 B 的基础上拆分“知识提取失败”和“概念或规则误解”。

如果 C 没有提升专家一致率或后续引导效果，就保留 B，不为分类精细度付出额外复杂度。

### 阶段 2：优化下一步帮助，不追求标签漂亮

主目标设为“学生下一轮独立新增覆盖的评分点比例”。同时记录提示泄漏、重复追问、对教师标签的归因一致率、完成用时和学生是否继续作答。

对每个原因维护固定帮助阶梯。先做提示词和检索增强；在至少有数百条高质量标注对话前，不建议微调。2026 年的诊断研究显示，小模型经过任务微调可以超过大模型，但它们依赖真实导师标签和严格的未见标签切分。项目当前更缺标注基准，而不是训练方法。

### 阶段 3：用真实学生做随机对照

对同一题型随机分配：当前流程、原因驱动流程、只按首个断点追问但不输出原因标签的流程。最后一组很重要，它能回答“提升来自归因，还是来自更聚焦的追问”。

测量三次：当场独立完整自讲、1 至 2 周后的延迟自讲、相邻迁移题。提示后答对只能说明受助表现，不能当作独立掌握。

## 六、评测体系

### 1. 归因层

| 指标 | 说明 |
| --- | --- |
| 首个断点一致率 | 与教师标注的步骤位置是否一致；这比原因标签更基础 |
| 原因 Macro-F1 | 防止高频“知识应用问题”掩盖小类失败 |
| Krippendorff's alpha / Cohen's kappa | 先测教师之间能否稳定区分这些原因；人都分不稳时不应要求模型分稳 |
| 拒答质量 | 在证据不足样本上选择“原因未明”的准确率，分别看误拒绝和强行归因 |
| 证据忠实度 | `evidence_spans` 是否来自学生原文，是否真的支持标签 |
| 稳定性 | 同义改写、ASR 噪声、答案长度变化后标签是否无故改变 |

### 2. 引导层

| 指标 | 说明 |
| --- | --- |
| 策略匹配率 | 帮助是否与主原因及当前断点匹配 |
| 答案泄漏率 | 是否直接给出当前问题或后续评分点答案 |
| 可回答性 | 学生凭现有信息是否能回答，问题是否单一明确 |
| 区分力 | 回答不同结果时，系统的下一步是否真的不同 |
| 新增评分点覆盖率 | 学生下一轮独立补出的新评分点数 / 本轮目标评分点数 |
| 无效重复率 | 是否重复已经问过、已经回答或已被提示泄漏的问题 |

### 3. 学习效果层

主指标建议使用“无帮助条件下完整解释的评分点覆盖率”。次指标包括正确率、首个断点后续修复率、近迁移、远迁移、延迟保持、每获得一个新评分点所需轮数和时间。

必须分开报告：

- 当场受助表现
- 立即独立表现
- 延迟独立表现
- 迁移表现

论文显示，解释质量、答案正确率和事实记忆可能出现不同方向的结果。只看“学生最后答对”会高估引导效果。

### 4. 上线护栏

- 分年级、题型、知识点、回答长度和输入方式报告误差。
- 抽查“归因为执行错误”的样本，防止系统把概念缺失轻率地归为粗心。
- 记录模型版本、提示词版本、原因、证据、实际发送内容和后续学生表现。
- 原因标签只用于当轮帮助；进入长期画像前，要求跨题重复证据和人工可追溯来源。

## 七、15 篇候选与筛选结果

下面 10 篇全部有实证评估。前 6 篇包含真实学习者的对照、随机或前后测；后 4 篇主要证明诊断或教学策略本身优于基线，不能替代真实学习效果实验。

### 保留 1：Evaluating AI Tutoring at the Speed of Innovation

- 主分类：真实学生学习效果 / 中学 AI 辅导
- 类型与状态：2026 预印本
- 作者与日期：Wayne Harrison、Rahil Khowaja、Emma Dobson、Germaine Uwimpuhwe、Steve Higgins；2026-09-13
- 原始链接：[arXiv:2609.14789](https://arxiv.org/abs/2609.14789)
- 证据：英国 GCSE 理化生四周多校个体随机试验；929 人完成前测，644 人完成后测。意向治疗分析中，AI 辅导相对常规自主复习的 Hedges' g = 0.33，95% CI [0.18, 0.48]。流失率 30.7%。
- 推荐理由：人群最接近本项目未来的中学生场景，而且任务包含课程对齐的书面解释与薄弱点适配。它证明短周期 AI 辅导可能有效，也给出了微随机试验的快速评测办法。
- 局限：预印本；后测非独立标准化；流失高且两组流失不完全相同；不能分离“归因、反馈、练习量”各自贡献。

### 保留 2：Practice Less, Explain More

- 主分类：LLM 支持的开放自讲
- 类型与状态：AIED 2026 已接收会议论文
- 作者与日期：Eason Chen 等；首次公开 2026-03-31
- 原始链接：[arXiv:2604.00142](https://arxiv.org/abs/2604.00142)；[DOI](https://doi.org/10.1007/978-3-032-29763-1_42)
- 证据：92 人组间实验，对比无自讲、菜单式自讲、带 LLM 反馈的开放自讲。开放自讲在“信息不足”迁移题上的解释质量比控制组高 11.9 个百分点，p = .030，d = 0.44；普通后测和迁移选择题正确率无显著差异。
- 推荐理由：和“让学生详细说出为什么”最直接。它支持开放简答与迭代反馈，也提醒项目把解释质量和答案正确率分开评测。
- 局限：微积分而非初中数学；关键结果集中在一种迁移题；解释由经人工一致性验证的 LLM 评分，仍应保留人工复核。

### 保留 3：Effects of specificity of self-explanation prompts for worked examples

- 主分类：自讲追问粒度
- 类型与状态：International Journal of Computer-Supported Collaborative Learning 同行评审论文
- 作者与日期：Dave Rexhäuser、Anika Radkowitsch、Constanze Richters 等；2026-03-23
- 原始链接：[DOI:10.1007/s11412-026-09468-9](https://doi.org/10.1007/s11412-026-09468-9)
- 证据：154 名汽车维修学员组成 77 对，前后测实验比较“具体自讲提示”“一般自讲提示”“直接解题”。自讲范例提高了诊断策略陈述知识和协作诊断过程质量，但没有提高策略应用，也没有降低认知负荷；直接解题的最终诊断结果更好；具体提示与一般提示无显著差异。
- 推荐理由：它反对无限细化问题。追问应该围绕一个关键断点，问题写得更具体并不自动带来更好迁移。
- 局限：协作诊断场景与数学不同；干预时间较短；结果显示陈述知识、过程和最终任务表现会分离。

### 保留 4：No Causal Self-Explanation Effect for Factual Knowledge

- 主分类：自讲有效边界
- 类型与状态：Applied Cognitive Psychology 同行评审、预注册实验
- 作者与日期：Benjamin Harders、Mirjam Ebersbach；2026-04-29
- 原始链接：[DOI:10.1002/acp.70174](https://doi.org/10.1002/acp.70174)
- 证据：N = 208，2×2 混合设计，对比自讲与重读，并测立即与两周延迟。保持时间有大效应，但学习策略无主效应，也无交互；正确自讲中的推理数量与成绩相关，复述数量不相关。
- 推荐理由：它是重要的反例。系统不应为了形式要求学生处处自讲；应引导产生新的推理连接，而不是增加复述长度。
- 局限：学习材料是虚构事实，不能否定数学推理中的自讲价值；它界定的是适用范围。

### 保留 5：Misconception Diagnosis From Student-Tutor Dialogue

- 主分类：错因诊断
- 类型与状态：ACM Learning at Scale 2026 口头论文
- 作者与日期：Joshua Mitton、Prarthana Bhattacharyya、Digory Smith、Thomas Christie、Ralph Abboud、Simon Woodhead；2026-02-02
- 原始链接：[arXiv:2602.02414](https://arxiv.org/abs/2602.02414)；[ACM DOI](https://doi.org/10.1145/3774398.3811609)
- 证据：922 条真实数学导师对话，546 个导师定义的误解标签，按未见标签切分；比较 TF-IDF、直接嵌入、零样本大模型与“生成-检索-重排”，并做阶段消融。微调 Qwen 2.5 7B 在多项低位次指标上可超过 Claude；重排把 73/229 个候选的正确标签推到首位。
- 推荐理由：它说明诊断不能只让模型在长枚举中直接分类。先生成可解释假设，再检索标准误解，最后重排，更适合未来建立学科错因库。它也证明真实导师标签和未见标签切分很重要。
- 局限：标签极稀疏，多数只出现一次；场景以选择题和导师对话为主；预测误解不等于证明该误解是因果原因。

### 保留 6：Fix the Mind, Not the Move

- 主分类：知识缺口定位与最小纠正
- 类型与状态：ICML 2026 已接收
- 作者与日期：Ayano Hiranaka、Ya-Chuan Hsu、Stefanos Nikolaidis、Erdem Bıyık、Daniel Seita；2026-06-04
- 原始链接：[arXiv:2606.05602](https://arxiv.org/abs/2606.05602)
- 证据：在三个长程任务中，把“定位哪个知识组件错了”和“如何纠正”拆开，测试多重误解的零样本组合泛化；20 人用户研究中，系统成功纠正 90% 的诱发误解，并改善后续任务表现。
- 推荐理由：这篇最支持“先定位首个知识断点，再给最小帮助”，也支持把定位和内容生成拆成两个可校验阶段。
- 局限：任务使用结构化 PDDL 知识和人为诱发误解，远比开放数学解释规整；20 人样本小，专家参考路径也可能压制有效替代解法。

### 保留 7：CircuTutor

- 主分类：错因驱动的 STEM 引导
- 类型与状态：2026 预印本
- 作者与日期：Ziyu Luo、Xiaorui Ma、Lin Chen、Xiaoming Chen；2026-09-08
- 原始链接：[arXiv:2609.08254](https://arxiv.org/abs/2609.08254)
- 证据：30 人随机分组，控制组与 CircuTutor 各 15 人。系统用物理仿真校验状态，映射答案差异到误解，再生成后续练习。控制前测后，后测显著更高，F(1,27)=5.89，p=.022，偏 eta squared=.18；迁移无显著差异，p=.650。另有 3 名专家评价 24 个案例。
- 推荐理由：它展示了可靠的实现边界：确定性领域求解器负责事实状态，模型负责解释和引导；错因后接相邻练习，而不是只给一段话。
- 局限：样本很小，预印本，控制组前测数值更高；后测有效但迁移未证明。

### 保留 8：TACT

- 主分类：学生行为到教学策略的路由
- 类型与状态：2026 预印本
- 作者与日期：Dongjie Yang、Siyan Lin、Leixian Shen、Rui Sheng、Huamin Qu、Zixin Chen；2026-08-04
- 原始链接：[arXiv:2608.03952](https://arxiv.org/abs/2608.03952)
- 证据：260 段真实一对一英语教学对话、32,379 条 taxonomy 标注、13 类教师策略、78 个真实诊断上下文。模型比骨干高 20.3 个百分点；50 名学习者的盲测中总体均分最高，为 5.54/7。
- 推荐理由：可直接借鉴“学生动作/状态 -> 有限教学策略”的契约。原因分类只保留能改变策略选择的维度，避免收集无用标签。
- 局限：没有学习结果；人类研究测的是主观教学行为；英语学习 taxonomy 不能直接搬到数学。

### 保留 9：Tackling the Root of Misinformation... / LFTutor

- 主分类：苏格拉底追问与意图路由
- 类型与状态：ACL 2026 主会长文已接收
- 作者与日期：Minjing Shi、Junling Wang、Jingwei Ni、Sankalan Pal Chowdhury、Mrinmaya Sachan；2026-05-31
- 原始链接：[arXiv:2606.01020](https://arxiv.org/abs/2606.01020)
- 证据：系统根据学生意图选择苏格拉底式与批判性论证策略；自动评价使用模拟学生，并由经人类核验的评判器评分；20 名参与者与系统交互并和基线比较，自动与人评均优于缺少这些策略的基线。
- 推荐理由：支持“先判断学生当前意图和回答状态，再选问题策略”，也给出发散、立场漂移、重复、缺少反驳等对话质量指标。
- 局限：人类样本小，主要是主观评价而非前后测；逻辑谬误场景与数学有差异；模拟学生结果不能当作学习效果。

### 保留 10：Evaluating Scaffolding-Oriented Multi-Agent LLM System for Clinical Interview Training

- 主分类：分工明确的多代理支架 / 随机对照
- 类型与状态：2026 预印本
- 作者与日期：Luming Yang、Haoxian Liu、Siqing Li、Rong Jia、Yue Xiao、Guanhua Chen、Li Lu；2026-09-10
- 原始链接：[arXiv:2609.10939](https://arxiv.org/abs/2609.10939)
- 证据：100 名医学生随机分组，95 人完成考试；多代理组和结构化非 LLM 控制组各完成两次训练，再在相同的仅病人代理环境考试。多代理组最终分数 71.8% 对 55.6%，回归差 16.4 个百分点；诊断正确率无显著差异，主要提升来自沟通、同理表达和部分病史采集行为。
- 推荐理由：它再次证明过程质量和最终结论可能分离。对 AI 自讲而言，完整解释、知识依据和最终答案应分别评分。代理分工也支持把“学生模拟、导师、过程评价”用于离线评测，但线上状态仍由确定性代码控制。
- 局限：医学场景；预印本；多代理系统同时改变多个因素，不能把提升归因于某个具体提示策略。

### 淘汰 11：Scaffolding Generative AI as a Tutor

## 八、合理性批判与不足

1. 2026 年的高相关论文多数很新，四篇保留论文仍是预印本。这里的“高质量”指当前实验设计和报告较完整，不代表已经经过长期复现。
2. 十篇中只有少数直接研究初中数学自讲。跨领域迁移的是判断原则和评测方法，原因标签仍需用本项目的真实数学对话重新验证。
3. 真实学生实验常把模型、界面、练习内容和策略一起改变，难以证明“归因”本身产生增益。项目必须加入“聚焦追问但不显式归因”的消融组。
4. 大模型给出的 `judge_reason` 可能流畅但不忠实。强制原文证据、允许“原因未明”、人工盲标和反事实测试缺一不可。
5. 当前代码与设计文档需要另行核对：设计文档包含“原因未明”，运行 schema 只允许五类，提示词还要求证据不足时强选一类。若要修改，这是公共输出契约变化，应先确定 JSON 表示、终态规则和历史数据兼容方式。

## 九、建议现在做什么

优先做一件事：建立 200 至 300 条教师双标的“首个断点 - 原因 - 证据 - 最小帮助 - 后续学生回答”基准，然后比较当前五分类、加入“原因未明”、拆分知识提取与概念误解三个版本。

这项工作能同时回答分类是否可判、模型依据是否忠实、引导是否有效。现在直接重写提示词或制作 Skill，最多得到更整齐的输出，无法证明学生因此讲得更完整。
