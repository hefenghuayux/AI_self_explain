| 段                        | 来源                        | 类型建议                | 导入规则 / 作用                                                    |
| ------------------------- | --------------------------- | ----------------------- | ------------------------------------------------------------------ |
| `id`                    | AI 自讲                     | `INTEGER`主键         | AI 自讲内部题目 ID                                                 |
| `tiku_question_id`      | `tiku_question.id`        | `INTEGER`，唯一、非空 | 原题库题目 ID，用于定位和防止重复导入                              |
| `question_content`      | AI 自讲 /`content`        | `TEXT`                | AI 自讲题干；导入时写入`tiku_question.content`                   |
| `standard_answer`       | AI 自讲 /`display_answer` | `TEXT`                | 标准答案；导入时由`tiku_question.answers`写入                    |
| `rubric_points`         | AI 自讲                     | `JSON`，可空          | 自讲必须覆盖的评分点；原题库没有则初始为`NULL`                   |
| `common_errors`         | AI 自讲                     | `JSON`，可空          | 常见错误；原题库没有则初始为`NULL`                               |
| `alternative_solutions` | AI 自讲                     | `JSON`，可空          | 可接受的其他解法；原题库没有则初始为`NULL`                       |
| `layered_hints`         | AI 自讲                     | `JSON`，可空          | 分层提示；原题库没有则初始为`NULL`                               |
| `guided_questions`      | AI 自讲                     | `JSON`，可空          | 人工预设的引导问题；原题库没有则初始为`NULL`                     |
| `full_solution`         | AI 自讲/`analysis`        | `TEXT`，可空          | 达到支持上限时展示的完整解析；原题库未纳入对应字段则初始为`NULL` |
| `grade_period`          | `grade_period`            | `SMALLINT`，可空      | 学段信息                                                           |
| `subject`               | `subject`                 | `VARCHAR(20)`，可空   | 学科，例如语文、英语对应的编码                                     |
| `q_type`                | `q_type`                  | `SMALLINT`，可空      | 题型编码                                                           |
| `difficulty_level`      | `difficulty_level`        | `SMALLINT`，可空      | 难度等级编码                                                       |
| `review`                | `review`                  | `VARCHAR(2048)`，可空 | 原题库的复习/补充说明，供录题人员理解题目                          |
| `archived_at`           | AI 自讲                     | `DATETIME`，可空      | AI 自讲侧归档时间，与原网站题目状态无关                            |
| `created_at`            | AI 自讲                     | `DATETIME`，非空      | AI 自讲记录创建时间                                                |
| `updated_at`            | AI 自讲                     | `DATETIME`，非空      | AI 自讲记录更新时间                                                |
| `topics`                | `topics`                  | TEXT                    | 题目主题或分类文本                                                 |
| `method`                | `method`                  | TEXT                    | 原系统解题方法或逐题讲解                                           |

`tiku_question` 与 AI 自讲字段的对应关系：

| `tiku_question`字段 | 新表字段             | 导入处理                                           |
| --------------------- | -------------------- | -------------------------------------------------- |
| `id`                | `tiku_question_id` | 原值复制；建立唯一约束                             |
| `content`           | `question_content` | 原值复制；保留 HTML 题干内容                       |
| `display_answer`    | `standard_answer`  | 原值复制或解析 JSON 后转为规范文本；需固定一种规则 |
| `topics`            | `topics`           | 原值复制                                           |
| `grade_period`      | `grade_period`     | 原值复制                                           |
| `subject`           | `subject`          | 原值复制                                           |
| `q_type`            | `q_type`           | 原值复制                                           |
| `difficulty_level`  | `difficulty_level` | 原值复制                                           |
| `review`            | `review`           | 原值复制                                           |
| `analysis`          | `full_solution`    | 原值复制                                           |
| `method`            | `method`           | 原系统解题方法或逐题讲解                           |
