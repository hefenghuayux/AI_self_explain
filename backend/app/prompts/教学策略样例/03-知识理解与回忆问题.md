# 知识理解与回忆问题：三个经典样例

## 使用说明

依据 `backend/app/prompts/generate_teaching.md` 当前版本编写。本文是构造的人工评审样例，输入为摘要；推荐 JSON 符合学生可见输出结构。动作由后端给定，均未触发解析展示阈值。原因分析与后续观察不属于模型输出字段。

本模块分别覆盖概念误解、规则混淆、适用条件不清。知识追溯只到当前卡点的直接依赖，不展开完整基础课程。会背公式和理解公式需要不同证据。

## 样例 1：异分母分数相加，不理解分母表示的单位

### 输入与约束

- 题目：计算 `1/2＋1/3`，并说明相加的方法。
- `task.currentStudentText`：「分子相加，分母也相加，所以二分之一加三分之一等于五分之二。」
- `latestEvaluation`：`WRONG + INCOMPLETE`；相加规则和结果错误，未说明统一分数单位的依据。
- 已提供历史：无。
- 当前目标：验证学生对分母与分数单位的理解。
- `allowedAction`：`CORRECT_AND_ASK`。
- `doNotRepeat`：无；`doNotReveal`：不提供通分结果、完整计算或标准答案；`responseGoal`：只检查分母含义这一项基础知识。

### 判断依据

优先假设为“知识理解与回忆问题”。学生明确给出了错误规则，证据强于一次算错；仍不能推断其从未学过分数，或认定所有分数知识都薄弱。

### 推荐输出

```json
{
  "content": "“分子相加，分母也相加”不符合分数加法的规则，这一步得到的结果不成立。先看清你相加的量表示什么。",
  "questions": [
    {
      "id": "knowledge_01",
      "question": "把一个整体平均分成若干份时，1/3中的3表示什么？"
    }
  ]
}
```

### 后续观察与质量标准

- 若能说明整体平均分成3份，说明这个概念至少能被提取；仍需新的证据判断是否理解不同分数单位如何相加。
- 若把3解释为“取了3份”，支持对分子、分母意义的误解，后续帮助应紧贴这一区别。
- 不合格写法：“先通分成六分之三和六分之二，再想想为什么。”把待建立的关键关系和操作直接给出，超出了本次诊断目标。

## 样例 2：同底数幂相乘，把乘法与幂的乘方混淆

### 输入与约束

- 题目：化简 `a²·a³＋a⁴`，并说明用到的运算规则。
- `task.currentStudentText`：「前面是同底数幂相乘，指数要相乘，所以a²乘a³等于a⁶。后面的a⁴与它不是同类项，保留加号。」
- `latestEvaluation`：`WRONG + COMPLETE`；已涉及乘法处理与后续合并判断，但把同底数幂乘法误用为指数相乘，表达式结果错误。
- 已提供历史：无。
- 当前目标：纠正 `a²·a³` 的局部规则。
- `allowedAction`：`GIVE_CORRECTION`。
- `doNotRepeat`：无；`doNotReveal`：不写整题化简结果；`responseGoal`：用因子数量解释当前局部规则。

### 判断依据

优先假设为“知识理解与回忆问题”。学生将错误操作明确说成规则，不能先归因于偶然笔误。`COMPLETE` 在此表示讲述涉及了所需步骤，不表示这些步骤正确。

### 推荐输出

```json
{
  "content": "“指数要相乘”用错了规则。a²是两个a相乘，a³是三个a相乘，两部分相乘共有五个a，因此这一局部应为a⁵。同底数幂相乘时指数相加；把这一依据补进你的乘法步骤。",
  "questions": []
}
```

### 后续观察与质量标准

- 学生复述“指数相加”属于接受纠正，不能单凭这句话确认规则已经理解。
- 后续若能自行用因子个数解释本步，并正确处理整题剩余部分，才提供更充分的理解与应用证据。
- 不合格写法：顺带讲解全部幂运算法则、负指数和零指数。当前只需修正这一个规则。

## 样例 3：记得勾股公式，不清楚斜边对应哪个量

### 输入与约束

- 题目：直角三角形斜边长13厘米，一条直角边长5厘米，求另一条直角边长。
- `task.currentStudentText`：「我记得a²+b²=c²，题目给了13和5，但我还不能确定该把它们放在哪里。」
- `latestEvaluation`：`CORRECT + INCOMPLETE`；公式回忆正确，未建立本题边长关系。
- 已提供历史：此前被问到公式中字母的含义时，学生说“c放哪条边都可以”；随后自讲仍只背公式，后端按无进展规则给定提示。
- 当前目标：明确勾股定理中斜边的位置。
- `allowedAction`：`GIVE_HINT`。
- `doNotRepeat`：不再让学生背公式；`doNotReveal`：不写本题求未知边的式子和最终长度；`responseGoal`：补上公式成立时的边的角色。

### 判断依据

优先假设为“知识理解与回忆问题”。已提供历史显示学生不理解公式中的角色约束，此时不能仅因其会背公式，就认定属于知识应用问题。

### 推荐输出

```json
{
  "content": "在a²+b²=c²这个写法中，c表示斜边，a和b表示两条直角边。先按题干给出的边的名称对应字母，再处理未知的那条边。",
  "questions": []
}
```

### 后续观察与质量标准

- 能把13对应斜边，说明这次提示帮助澄清了角色；接下来的列式是否正确仍需单独评价。
- 若已能稳定说明字母含义，却继续不知道如何把已知量代入，才出现更支持知识应用问题的证据。
- 不合格写法：“你已经会勾股定理，只是不细心。”会背公式不能证明懂得适用条件，也没有“不细心”的证据。

## 合理性批判与不足

1. 一个基础问题只能检验局部概念，不能代表整章掌握水平；追溯过多还会打断学生当前解题，增加不必要负担。
2. 直接纠正和提示提供了知识内容，能推动当前步骤，但会降低后续回答作为独立掌握证据的强度。评审时应保留这一差别。
